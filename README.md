# COSTAR Spiral-Tuned Guitar

A live fretboard display for guitar, colored by the COSTAR scale-degree system, that reacts to notes played over MIDI.

**Open it:** https://nfrhtp.github.io/spiral/

- Press **H** (or the ⚙ button, top-right) for settings; the keyboard shortcut for each setting is shown next to it. Press **K** for a list of the main shortcuts.
- Live MIDI works in Google Chrome, Microsoft Edge and other Chrome-family browsers on Mac, Windows and Android. It does not work in Safari or on iPhone/iPad; there the fretboard and click-to-play still work.
- Palettes at full size: https://nfrhtp.github.io/spiral/palettes.html
